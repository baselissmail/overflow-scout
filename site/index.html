Overflow Scout
Privacy GitHub

Find text that gets cut off, before your users do.

Overflow Scout is a Chrome extension for developers and QA. It finds text that's clipped, truncated or overflowing, shows what breaks once your text is translated, and checks CSS fixes on the page itself.

Add to Chrome

What it does

  • Scan pageEvery text that's clipped with no cue, ends in an ellipsis, runs out of its box, or makes the page scroll sideways, and how much doesn't fit.
  • Test with longer textMakes every text as long as a translation would be, shows what breaks, then puts the page back exactly.
  • Fixes checked on the pageEach suggested CSS fix is tried for a moment and measured, so you know whether it works.
  • Measure an elementSee how many characters fit, and try real names, links, emails or your own text live.
  • ReportsCopy Markdown for GitHub or Jira, a cropped screenshot, or save everything as JSON.
  • PrivateRuns entirely in your browser. No data collected, no analytics, no network requests.
