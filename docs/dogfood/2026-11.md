# Dogfooding, November 2026 (Phase 6)

`pnpm dogfood` runs the detection engine on each site below in Chromium (1280×800, English, after load plus 2.5 s). It scans, runs the default longer-text test, and writes a contact sheet per site: every finding, cropped, with its box outlined. Findings were judged by eye on the sheets and, where a crop wasn't clear, on the live page. The sheets aren't committed; rerun the script to see them.

## False positives: 1 of 34 (2.9%)

The exit gate is under 5%. The one left:

- **ant.design**: a menu group title at the bottom of the sidebar is reported as cut off. The sidebar hides its overflow and scrolls only while hovered (`overflow-y: auto` on `:hover`). Recorded as a limitation in `tests/fixtures/limitations/intentional-previews.html`; recognizing it means reading the page's style rules.

## What the 33 others are

- **Truncated, as designed (32)**: GitHub's commit messages and issue links end in an ellipsis (28), Booking's date field label, Linear's and shadcn's two-line clamps. Truncation is reported as a warning because the end of the text is lost, even when that's intended.
- **Overflows (1)**: on Shopify, a large stat's "+" is 7 px wider than the flex item that shrank around it.

Each fixture fails with the engine from `main` and passes now. One more came up after the code review tightened the scroll rule: on Linear, a diff line's tint ends where the code scrolls on, which counted as crossing a visible edge. Code in a scroll container is meant to scroll, so preformatted text is exempt (`known-good/scroll-containers.html`). True positives next to them (a teaser whose text lands on the line below, a toolbar label that can't shrink, a fixed-width line in a clipping column) pass both before and after, so the rules don't hide real problems.

## False negatives

Live sites have no ground truth, so misses can't be counted here; the corpus measures recall (100%). The longer-text column shows the stress test finding work on most sites: Amazon (24), Linear (18), shadcn (15) and Booking (14) have the most text that breaks once translated.
